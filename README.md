# Unnamed Stremio/Kodi Alternative

An open-source, local-first media center: Stremio-addon compatible, runs Kodi video addons via a compatibility layer, and introduces its own addon protocol. Fully themeable/skinnable/moddable, built for both PC and TV/controller.

**Planning docs:** see [`docs/`](docs/README.md).
